1. OLS Estimation

The OLS estimator is β̂ = (X′X)−1X′y. The estimated error variance is based on the residual sum of squares divided by n − k, and t-values are coefficients divided by their estimated standard errors.

ols_est <- function(X, y) {
  # Make sure inputs have convenient matrix/vector forms
  X <- as.matrix(X)
  y <- as.numeric(y)

  n <- nrow(X)
  k <- ncol(X)

  # OLS coefficient estimates
  bhat <- solve(crossprod(X), crossprod(X, y))
  bhat <- as.numeric(bhat)

  # Residuals and estimated error variance
  uhat <- y - as.numeric(X %*% bhat)
  sigma2_hat <- sum(uhat^2) / (n - k)

  # Conventional variance matrix, standard errors, and t-values
  vcov_hat <- sigma2_hat * solve(crossprod(X))
  se_hat <- sqrt(diag(vcov_hat))
  t_values <- bhat / se_hat

  # Preserve coefficient names when X has column names
  if (!is.null(colnames(X))) {
    names(bhat) <- colnames(X)
    names(t_values) <- colnames(X)
  }

  list(coefficients = bhat, t_values = t_values)
}

2. Monte Carlo Simulation

The simulation uses α = 0.11, β₁ = 0.22, β₂ = 0.33, ρ = 0.5, σ₁ = 1, σ₂ = 4, n = 100, and 1000 replications.

Step 1: Data generating function

dgp <- function(n, alpha, beta, rho, sigma1, sigma2) {
  # Mean vector and covariance matrix for (x1, x2)
  mu <- c(0, 1)
  Sigma <- matrix(
    c(
      sigma1^2, rho * sigma1 * sigma2,
      rho * sigma1 * sigma2, sigma2^2
    ),
    nrow = 2,
    byrow = TRUE
  )

  # Draw from a bivariate normal using a Cholesky factor
  Z <- matrix(rnorm(2 * n), nrow = n, ncol = 2)
  Xdraw <- sweep(Z %*% chol(Sigma), 2, mu, FUN = "+")

  x1 <- Xdraw[, 1]
  x2 <- Xdraw[, 2]
  u  <- rnorm(n)

  y <- alpha + beta[1] * x1 + beta[2] * x2 + u

  data.frame(y = y, x1 = x1, x2 = x2)
}

Step 4: Summarize Results

sum_results <- function(estimates, true_values) {
  estimates <- as.matrix(estimates)
  true_values <- as.numeric(true_values)

  bias <- colMeans(
    sweep(estimates, 2, true_values, FUN = "-")
  )

  rmse <- sqrt(
    colMeans(
      sweep(estimates, 2, true_values, FUN = "-")^2
    )
  )

  data.frame(
    parameter = colnames(estimates),
    true_value = true_values,
    bias = as.numeric(bias),
    RMSE = as.numeric(rmse),
    row.names = NULL
  )
}

Step 5: Interpret your results

The estimated biases are very close to zero, as expected under a correctly specified regression with a mean-independent error. The empirical distribution of β̂₁ is centered near the true value β₁ = 0.22. RMSE is positive because estimates vary across samples. Because x₂ has much greater variation than x₁ in this design, β₂ is estimated more precisely and typically has a smaller RMSE.

The misspecified regression produces a large positive bias in β̂₁ because x₂ is omitted even though it is positively correlated with x₁ and has a positive effect on y. The probability-limit coefficient on x₁ is β₁ + β₂ Cov(x₁,x₂)/Var(x₁) = 0.22 + 0.33·2 = 0.88, so the asymptotic omitted-variable bias is about 0.66. The Monte Carlo result is close to that value.
